# Roblox Countdown Manager

Turn any game icon into a live countdown: 6h, 4h, 2h, 1h, NOW, then your new icon.

- Add your current icon and your new icon
- Edit the steps, launch time, badge color, size and position
- Black clock badge with the number under it
- Switches by itself on schedule and can auto-copy each image
- Copy, save or download every image
- Works on PC and phone, installable as an app

Live page: https://Racinggamemakerpro67.github.io/roblox-countdown-manager/
